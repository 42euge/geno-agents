geno-agents

Agent coordination layer — registration, discovery, and role management for multi-agent systems

coordination python cli

The Problem: Skills ≠ Coordination

Every multi-agent framework focuses on what agents can do (skills, tools, prompts). None solve how agents find each other and coordinate work.

Giving agents a chat room doesn't make them collaborate any more than putting 5 strangers in a Slack channel makes them a team.

We observed this firsthand: autonomous Claude Code sessions messaging each other with no context about who they're talking to, what the other agent does, or whether it's even listening. Messages go unread. Help requests get no response. Agents cold-email strangers.

Quick Start

# Install
pip install -e path/to/geno-agents

# Register your agent
geno-agents register "benchmark-agent" \
  -d "Kaggle benchmark tasks" \
  -c kaggle -c benchmarks

# See who's online
geno-agents ls

# Find who handles browser stuff
geno-agents who "browser"

Commands

geno-agents register <role>Register with a role, description, and capability tags
geno-agents unregisterRemove this agent from the registry
geno-agents lsList all registered agents with roles and status
geno-agents who <query>Find agents by role or capability
geno-agents heartbeatUpdate presence (last seen, available/busy)
geno-agents pruneRemove stale agents not seen in 10+ minutes

Roadmap

✓ Agent Registry

Register with role, description, and capabilities. Discover agents by role or capability.

✓ Presence

Heartbeat, available/busy status, stale agent pruning.

→ Task Board

Shared task lifecycle — delegate, accept, track progress, complete. Contract-net style negotiation.

→ Auto-Registration

Claude Code hook to register on session start. Role inferred from CLAUDE.md or skill context.

○ Shared Context

Project state document — goals, progress, who's editing what. The missing "blackboard."

○ Intent & Locks

Declare intent before editing files. Prevent conflicts between concurrent agents.

The Gap in Multi-Agent Frameworks

Skills Frameworks

Solve "what can an agent do?"
SKILL.md, MCP servers, tool definitions.

geno-agents

Solves "who's here and what are they doing?"
Registration, discovery, coordination.

No existing framework — CrewAI, AutoGen, LangGraph, A2A, OpenAI Swarm — solves all three of: dynamic discovery, task lifecycle with negotiation, and distributed shared context. Most assume you hardcode your agents at design time.
